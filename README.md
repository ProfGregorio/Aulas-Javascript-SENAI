# 📖 Conteúdo Aprendido

## 🟢 Aula 01 - Introdução ao JavaScript

### Conceitos estudados

* `alert()`
* `prompt()`
* `confirm()`
* Variáveis (`let`)
* Tipos de dados
* Concatenação de strings
* Operações aritméticas
* `console.log()`
* Conversão de dados (`parseInt()` e `parseFloat()`)
* Estruturas condicionais (`if` e `else`)

### O que foi praticado

* Exibição de mensagens ao usuário
* Entrada de dados via teclado
* Confirmação de ações
* Integração entre HTML e JavaScript
* Criação de calculadoras simples

---

## 🟡 Aula 02 - Manipulação do DOM

### Conceitos estudados

#### Seleção de elementos

```javascript
document.getElementsByTagName()
```

#### Alteração de conteúdo

```javascript
element.innerText
```

```javascript
element.innerHTML
```

#### Manipulação de estilos

```javascript
element.style.backgroundColor
element.style.color
element.style.fontSize
```

#### Escrita dinâmica

```javascript
document.write()
```

### O que foi praticado

* Alteração de textos da página
* Alteração de estilos CSS via JavaScript
* Manipulação de elementos HTML
* Troca dinâmica de imagens
* Criação e utilização de funções

---

## 🔵 Aula 03 - Eventos e Formulários

### Conceitos estudados

#### Seleção por ID

```javascript
document.getElementById()
```

#### Eventos

```html
onclick=""
```

#### Funções

```javascript
function minhaFuncao() {

}
```

#### Manipulação de formulários

* Inputs
* Captura de valores
* Conversão de tipos
* Exibição de resultados

### O que foi praticado

* Troca de imagens através de botões
* Calculadora utilizando formulários
* Limpeza de campos
* Atualização dinâmica de conteúdo na página

## 🚀 Publicação dos Exercícios

Além de desenvolver os exercícios e desafios propostos, cada aluno deverá criar seu próprio repositório no GitHub e publicar seus projetos utilizando o GitHub Pages.

### Objetivos

* Praticar versionamento com Git e GitHub;
* Aprender a publicar projetos na web;
* Construir um portfólio de desenvolvimento desde o início do curso;
* Compartilhar seus projetos com colegas, professores e recrutadores;
* Registrar sua evolução ao longo das aulas.

### Entrega

Ao final de cada aula ou desafio, recomenda-se:

1. Fazer commit das alterações;
2. Atualizar o repositório remoto no GitHub;
3. Publicar ou atualizar o GitHub Pages;
4. Compartilhar o link do projeto quando solicitado.

> Um desenvolvedor não apenas escreve código: ele organiza, versiona, documenta e publica seus projetos.

# 💡 Recomendações para os Alunos

Programação é uma habilidade desenvolvida através da prática constante. Por isso, não se limite apenas a assistir às aulas: execute todos os exercícios, tente resolver os desafios sem consultar as respostas e experimente criar suas próprias variações dos exemplos apresentados.

Embora o foco principal deste curso seja o **JavaScript**, é fundamental que o aluno também desenvolva boas práticas em:

* 🎨 **CSS**: invista tempo na estilização das páginas para melhorar a experiência visual dos seus projetos.
* 🏗️ **HTML5 Semântico**: utilize as tags apropriadas para estruturar corretamente o conteúdo, tornando suas páginas mais organizadas, acessíveis e profissionais.
* ✅ **Validação de Código**: valide seus arquivos HTML utilizando o **W3C Validator** para identificar erros e garantir a conformidade com os padrões da web.

👉 W3C Validator: https://validator.w3.org/
